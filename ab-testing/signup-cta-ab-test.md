# Signup CTA A/B Test

**Artifact type:** Portfolio Simulation

## Hypothesis

A task-oriented CTA will increase signups for a frontend learning platform because users will understand the immediate value of starting.

## Control

Button label: "Sign Up"

## Variant

Button label: "Start Learning Frontend"

## Primary Metric

Signup start rate.

## Secondary Metrics

- Account completion rate
- Lesson start rate after signup
- CTA click-through rate
- Bounce rate from the signup page
- Return visits within seven days

## Sample Size Considerations

The test should run long enough to capture weekday and weekend usage patterns. If traffic is limited, the team should avoid overinterpreting small differences and pair the test with usability observations.

## Expected Result

The variant is expected to increase CTA clicks because it makes the outcome more concrete.

## Decision Rule

Adopt the variant only if signup starts increase and account completion does not decrease. A higher click rate with lower completion may indicate misleading or premature CTA language.

## Follow-Up Action

Test CTA copy by user intent, such as "Practice Accessible Forms" for learners entering from accessibility content.

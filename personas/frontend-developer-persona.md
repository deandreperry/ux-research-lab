# Frontend Developer Persona

**Artifact type:** Portfolio Simulation

## Background

Jordan is a frontend developer responsible for turning product requirements and design specs into reliable web interfaces. They care about performance, maintainability, accessibility, and clean implementation patterns.

## Goals

- Build UI that matches design intent and works for real users.
- Find trustworthy examples quickly.
- Avoid accessibility regressions.
- Reduce ambiguity in acceptance criteria.

## Needs

- Clear implementation guidance
- Expected behavior for edge cases and states
- Accessible markup and interaction examples
- Fast troubleshooting when local setup or tests fail

## Pain Points

- Designs sometimes lack behavior details.
- Documentation may be outdated or incomplete.
- Accessibility requirements are not always testable.
- Error messages can point to symptoms instead of causes.

## Behaviors

- Scans documentation before reading deeply.
- Tests interactions in browser dev tools.
- Searches issue threads when examples fail.
- Asks for clarification when design states are missing.

## Tools Used

Code editor, browser dev tools, Git, npm, component libraries, Storybook, accessibility browser extensions, automated tests, and issue trackers.

## Accessibility Considerations

Jordan benefits from guidance on semantic HTML, keyboard support, ARIA use, focus management, form validation, and screen reader expectations.

## Product Opportunities

- Provide code examples with expected output.
- Add accessibility acceptance criteria to pattern pages.
- Include troubleshooting paths for common setup and implementation errors.

# Task Scenarios

**Artifact type:** Portfolio Simulation

## Scenario Context

You are learning frontend development and want to improve how you build accessible forms. You are using an interactive learning platform that combines short explanations, code tasks, visual previews, and feedback.

## Task 1: Find The Right Lesson

**Prompt:** You want to learn how to show useful validation errors in a form. Find the lesson you would start with.

**Success Criteria:**

- User finds a relevant form validation lesson.
- User can explain why the lesson matches their goal.
- User does not rely on moderator guidance.

## Task 2: Understand The Lesson

**Prompt:** Open the lesson and describe what you think it will teach you.

**Success Criteria:**

- User identifies the lesson objective.
- User understands prerequisites.
- User knows the next action.

## Task 3: Complete A Code Step

**Prompt:** Follow the first instruction and update the sample form.

**Success Criteria:**

- User completes the required change.
- User notices the visual preview or feedback state.
- User understands whether the step passed.

## Task 4: Recover From An Error

**Prompt:** Something in your code is not working. Use the feedback to decide what to change.

**Success Criteria:**

- User reads and interprets the error feedback.
- User attempts a relevant fix.
- User can explain what went wrong.

## Task 5: Choose What To Do Next

**Prompt:** You finished the first lesson. Find what you would do next.

**Success Criteria:**

- User locates progress or completion state.
- User understands the next recommended lesson.
- User can decide whether to continue, review, or exit.

## Observations To Capture

- Time on task
- Misclicks or wrong turns
- Confusing labels or instructions
- Emotional reactions
- Recovery behavior
- Accessibility barriers
- Suggestions in participant language
